# Segurança do MPPT24 CORE

## Comunicar um problema em privado

No separador [Security](https://github.com/mppt24/mppt24-core/security), usa **Report a vulnerability** se a opção estiver disponível. Caso contrário, pede um canal privado numa issue pública sem publicar detalhes do problema.

No canal privado, inclui a versão ou commit afetado, o impacto observado e os passos necessários para compreender o problema. Usa dados fictícios ou expurgados de informação pessoal.

## Registos para diagnóstico

O [guia de leitura](GUIA.md#como-ler-os-registos) explica como identificar o resultado de uma suite. Partilha excertos mínimos: a etapa, o resultado e o contexto relevante. Mantém credenciais, relatórios reais e detalhes da rede fora de issues e pull requests públicos.

Executa os testes de integração num ambiente que controlas. Antes de instalar a base pública num servidor em uso, lê os [requisitos e limites de instalação](README.md#instalação).
